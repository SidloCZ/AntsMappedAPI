API Reference

RESTful API Endpoints

All endpoints return standard HTTP responses with CORS enabled, browser and CDN cache headers, and high-performance in-memory rendering.

GET /map/{species_name}.png

Dynamically renders and returns a high-resolution PNG distribution map for any ant species or subspecies.

Parameter Type Default Description
species_name path string required Scientific binomial or trinomial name (e.g. Lasius_niger, Formica_picea_formosae).
proj query string equal_earth Cartographic projection: equal_earth, plate_carree, mercator.
theme query string dark Color theme: dark (optimized for Discord) or light (publication white).
lang query string en Legend language: en (English) or cs (Čeština).
GET /map/genus/{genus_name}.png

Returns an aggregated global distribution map of all species and records within the specified genus.

GET /api/v1/distribution/{species_name}

Returns structured JSON with all sub-national biogeographic regions (GABI bentities) and establishment status.

GET /api/v1/search?q={query}&limit=20

Fulltext autocomplete search across all 15,460+ ant species and subspecies.

GET /api/v1/citations

Returns required scientific citations and licensing metadata for Kass et al. (2022) and Wong et al. (2023).

Scientific Attribution

Citations & Mandatory Attribution

This service compiles data from peer-reviewed scientific literature. Any bot, publication, or app utilizing this API must cite the following primary authors:

GABI Database (Kass et al. 2022)

Kass, J. M., Guénard, B., Dudley, K. L., Jenkins, C. N., Azuma, F., Fisher, B. L., Parr, C. L., Phang, D. E., Schultheiss, P., Shattuck, S. O., Suhr, E. L., & Economo, E. P. (2022). The global distribution of known and undiscovered ant biodiversity. Science Advances, 8(31), eabp9908.

Alien Ant Species (Wong et al. 2023)

Wong, M. K. L., Economo, E. P., & Guénard, B. (2023). The global spread and drivers of alien ant species. Nature Communications, 14, 8398.

Equal Earth Projection (Šavrič et al. 2018)

Šavrič, B., Patterson, T., & Jenny, B. (2018). The Equal Earth map projection. International Journal of Geographical Information Science, 33(3), 454–465.

Mandatory Discord Embed Footer

When sending maps to Discord via bot embeds, you must include the following attribution in the embed footer:
