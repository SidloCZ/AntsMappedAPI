API Reference

RESTful API Endpoints

All endpoints return standard HTTP responses with CORS enabled, browser and CDN cache headers, and high-performance in-memory rendering. Test any endpoint live directly in the console below.

GET /map/{species_name}.png

Dynamically renders and returns a high-resolution PNG distribution map for any ant species or subspecies.

Parameters
Parameter In / Type Default Description
species_name required path string — Scientific binomial or trinomial name (e.g. Lasius_niger, Formica_picea_formosae).
proj optional query string equal_earth Cartographic projection: equal_earth, plate_carree, mercator.
theme optional query string dark Color theme: dark (Discord-optimized) or light (publication white).
lang optional query string en Legend language: en (English) or cs (Czech).
Status Codes & Headers
Status Content-Type Description
200 OK image/png Distribution map successfully rendered (Cache-Control: public, max-age=86400).
404 Not Found application/json Species not found in the GABI ant distribution database.

GET /map/genus/{genus_name}.png

Returns an aggregated global distribution map of all species and records within the specified genus.

Parameters
Parameter In / Type Default Description
genus_name required path string — Ant genus name (e.g. Camponotus, Lasius, Formica, Myrmica).
proj optional query string equal_earth Cartographic projection: equal_earth, plate_carree, mercator.
theme optional query string dark Color theme: dark or light.
lang optional query string en Legend language: en (English) or cs (Czech).

GET /api/v1/distribution/{species_name}

Returns structured JSON with all sub-national biogeographic regions (GABI bentities) and establishment status.

Parameters
Parameter In / Type Default Description
species_name required path string — Scientific binomial or trinomial name (e.g. Lasius_niger).
Try It Out Console
GET /api/v1/distribution/{species_name}
200 OK application/json ~4 ms
GET /api/v1/search?q={query}&limit=20

Fulltext autocomplete search across all 15,460+ ant species and subspecies.

Parameters
Parameter In / Type Default Description
q required query string — Search query substring or abbreviation (e.g. Lasius, niger, L. niger).
limit optional query integer 20 Maximum number of search results to return (1 to 100).
Try It Out Console
GET /api/v1/search
200 OK application/json ~2 ms

Citations & Mandatory Attribution

This service compiles data from peer-reviewed scientific literature. Any bot, publication, or app utilizing this API must cite the following primary authors:

GABI Database (Kass et al. 2022)

doi: 10.1126/sciadv.abp9908
